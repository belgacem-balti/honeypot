Wazuh Integration Setup

To dynamically forward live alerts from your Wazuh Manager into this AI SOC dashboard, add this integration block to your Wazuh Manager configuration:

1. In /var/ossec/etc/ossec.conf: 
<ossec_config>
  <integration>
    <name>custom-threat-analyzer</name>
    <hook_url>http://127.0.0.1:8080/api/wazuh</hook_url>
    <level>5</level>
    <alert_format>json</alert_format>
  </integration>
</ossec_config>
2. Script in /var/ossec/integrations/custom-threat-analyzer: 
Available at: ai-soc-dashboard/wazuh/custom-threat-analyzer.py
Command: chmod 750 && chown root:ossec
