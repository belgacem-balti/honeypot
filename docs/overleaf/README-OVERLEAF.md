# Overleaf (recompile this version)

The previous dark PDF looked messy: tables overflowed, figures floated away from their text, and there was no table of contents.

This `main.tex` is a **light, structured** report:

- table of contents
- numbered sections in reading order
- tables that fit the page
- each screenshot locked next to a grey **How to read this figure** box

## Upload

1. Overleaf → Menu → Compiler = **pdfLaTeX**
2. Replace `main.tex` with this file
3. Keep / re-upload `figures/` (`00`–`11`.png)
4. **Recompile twice** (needed for the table of contents)

Do not keep the old dark `main.tex` in the same project.
